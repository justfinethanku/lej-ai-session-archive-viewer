## Design pass, November 15, 2026

The interface was restyled to LEJ Design System v1 on branch `design/lej-pass`. Data reading is unchanged. Three things changed outside presentation:

- The server now sends any `.css`, `.js`, `.woff2` or `.svg` file that ships in `static/`, matched by exact name, so the bundled fonts and icon can load. The Content-Security-Policy gained `font-src 'self'` and `img-src 'self'`.
- Tags are edited as rows (a name and comma-separated keywords) in place of a JSON box. The saved format is the same. A keyword cannot contain a comma when edited this way; `config.json` still allows it.
- The page opens on Sessions once an index exists, and on Sources only for a new install. Folders you added yourself can be removed from the Sources screen.

Checks after the pass: 20 unittest cases pass with zero skips, now including the font and icon routes, the font policy, and 404s for paths outside the shipped static files. `node --check static/app.js` passes. The public-content scan was run again over every file, with the same checks as below: zero matches for personal paths, names, client terms, emails or token shapes. At-sign matches are CSS at-rules, Python decorators and GitHub Actions versions. The screenshots in docs/design/ were taken from tools/demo.py data, hold no text metadata, and were each produced from the demo ports. No remote exists and nothing was pushed.

Text contrast was computed for both color schemes: every text pairing used is 4.7:1 or better. The fonts are the Latin and Latin Extended subsets of Bricolage Grotesque, Hanken Grotesk and JetBrains Mono, with their SIL Open Font License files beside them.

## Practical limits

Refresh rebuilds enabled stores, so a large archive takes minutes and source failures can leave partial results. It does not provide an atomic whole-archive replacement. Active writers can exhaust snapshot retries; refresh again during a quiet moment. Discovery creates private database snapshots even before indexing is enabled. Disabling a source removes its searchable records on refresh but retains snapshots/imported originals in app data. Formats are internal and can change. Cursor JSONL timestamps are unavailable. Attachment rendering, cross-app deduplication, cloud sync and secret redaction are outside this version.
